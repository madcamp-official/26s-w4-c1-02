## 1. 30초 요약 — 지금 어디에 서 있나

**계획보다 하루 빠르다.** Day 2 저녁 기준으로 G1 이 닫혔고, G2 는 화면 "붙이기" 하나만 남았고,

```

  화면: URL 붙여넣기 → 진행 연출 → 실수집 미리보기 → 저장 → 표  ✅  (07-27 배선)
  배포: https://endpoint.madcamp-kaist.org  ✅  (VPN 불필요 · 정식 인증서)
```

그리고 **델타가 G3 이후의 그림을 바꿨다** — 구독 대신 뷰, 피드 대신 작업실, 인프라 능동성을 화면으로.

## 3. Day 1~2 에 끝난 것 (검증된 것만)

**트랙 A** — 상세는 [day2-part-a.md](./day2-part-a.md)
- probe 4단계(DOM 반복 구조 포함) · Gemini 컴파일 · 수리(repair-empty·verify-link) · SSRF 관문 · EUC-KR charset
- G1: 낯선 URL 4곳 전부 표 (컴파일 LLM 2회, 수집 경로 LLM 0회)
- G2(CLI): 접합 자동 매핑 5/6 · 못 찾은 칸 값 붙여넣기(traceValue) · 두 출처 30건이 한 표로 API 응답
- 워커 HTTP 문 (ADR A30) — 화면이 부르는 진입점

**트랙 B**
- 클로드 디자인 전면 적용 · 랜딩/목록/표/읽기 피드/구독/연결/관리 화면 · 구글 로그인 실기 확인
- 컬렉션 생성 화면(4단계 연출·열 편집) — 07-27 워커 문에 **실배선 완료** (G2 의 화면 절반)
- 웹훅 구독 등록/해지 · MCP JSON-RPC 실측(도구 4개·SSE) · B2 자동 점검 48개

**공동**
- 두 트랙 머지 (충돌 해소 · ADR 번호 재정렬 A31/A32)
- 배포: VM + Docker + Caddy + **Cloudflare Tunnel** — 화면·API·MCP 세 도메인 공개, 정식 인증서

## 4. 델타가 바꾼 것 (요약)

1. **강점 재정의** — 정의권 · 원문 대조 · 지속 ("자유도" 금지)
2. **뷰 일급 객체** — 구독 탭 → 작업실 탭. 기본 표 = 뷰 #0. 네 출구가 같은 쿼리 코드
3. **능동성** — 관찰한 걸 말해주는 입: 상단 상태 줄 · 소스 침묵 감지. 추천은 금지

**v1 필수 셋** (이 셋 없이 나머지를 만들면 다시 짠다): 뷰 저장 · `enter` 전이 · 뷰 건강.
확정 결정은 ADR A33~A39 로, 미결은 열린 결정 O9~O13 으로 승격했다.

## 5. 재분배 — Day 3~5

원칙은 그대로다: **경계는 디렉터리, 판단이 필요한 곳에 사람.** 뷰 계약은 core 공유물이므로 공동으로 고정한다.

### Day 3 아침 — 공동 30분 (이것부터)

| 결정 | 내용 |
|---|---|
| **뷰 계약 고정** | `View` 타입(where·sort·columns·notify·owner·health) + 술어 닫힌 집합(A35) + `views`·`view_matches`·`notification_dedupe` 마이그레이션. G0 계약 #6 으로 승격 |
| O9 대상 사용자 | 온보딩·발표에서 누굴 앞에 세우나 (권장: 비개발자) |
| O10 schema_version | 의미 확정 (권장: 경고만 + 뷰는 `broken` 처리) |

### Day 3 — G3: 계속 돈다

| | **트랙 A — 파이프라인** (`apps/worker` · core 뷰 평가) | **트랙 B — 표면** (`apps/web` · `apps/mcp`) |
|---|---|---|
| 핵심 | **`enter` 전이 감지** — 뷰별 매칭 집합 저장 + run 차집합 (A34) | **뷰 저장** — 표에서 필터 걸고 "이 조건 저장" → 이름 자동 제안 (델타 2-10) |
| | **뷰 평가 일일 잡** — 수집과 분리 (시간 전이 D-8→D-7) | **작업실 탭** — 구독 탭 개편: 뷰 카드(조건·건수·최근 enter·건강) + 소스 정비 + 채널 |
| | **소스 침묵 감지** — run 신규 추이 → "3주째 조용함" | **상단 상태 줄** — "3시간 전 확인 · 새 항목 2건 · D-3 이내 3건 · ⚠…" |
| | 두 번 연속 수집 → 신규 0 검증 (`external_key` 안정성) | 뷰 건강 문구 (`warn`/`broken` 을 사람 말로 — B2) |
| | `normalizeIdentity` 수정 (**core → B 통보**) + 치유 실검증(감지→격리→재컴파일→승격) | **"사이트 붙이기" 화면** — attach 를 워커 문으로 노출받아 G2 를 닫는다 (못 찾은 칸 = 값 붙여넣기 · B1) |
| | 수동 수집 트리거 (워커 문에 경로 추가 — 데모의 "일부러 깨뜨리기" 경로) | 예시 컬렉션 3~4개 (빈 화면 금지 · 델타 5-5) |
| 저녁 판정 | gates.md G3(A) — 깨뜨려도 혼자 고치고 나머지는 산다 | gates.md G3(B) — 조건 저장 → enter 알림 1회 전송 |

- attach 의 워커 문 노출(`POST /internal/attach` 류)은 **A 가 문을 내고 B 가 화면을 붙인다** — preview/collections 와 같은 계약 방식.
- 알림 발송(채널 dedupe · A36)은 A 의 deliver 잡 + B 의 채널 화면이 만나는 지점 — Day 3 저녁 합류로 판정.
