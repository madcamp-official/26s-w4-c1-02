# 비개발자 보장선 B1~B7 — 점검 절차

> 기획서 4-1 을 **들고 화면을 도는 문서**로 옮긴 것. G4 전수 점검에서 이 순서대로 본다.

## 이 문서의 위치

보장선은 구호가 아니라 **검수 가능한 제약**이다. 어느 하나라도 깨지면 그 기능은 미완성으로 판정한다.
기획서 5장은 사수 대상을 셋으로 못 박았다 — **②소스 접합 · ④자가 치유 · B1~B7 보장선.**
②와 ④가 아무리 잘 돌아도 보장선이 깨지면 이 제품은 Firecrawl 의 열등한 사본이다.

**개발자를 위한 것은 빼는 게 아니라 접는다.** B5 가 그 원칙을 대표한다.
지훈이 원하는 건 다 있되, 수영의 첫 화면에는 안 나온다. 화면을 두 벌 만드는 게 아니라 접힘 상태만 다르다.

## 점검하는 법

1. **로그인부터 다시 한다.** 이미 만들어 둔 컬렉션 화면에서 시작하면 첫 진입의 문제를 못 본다.
2. **개발자 도구를 닫고 본다.** B4·B5 는 "화면에 무엇이 보이는가"가 판정 기준이다.
3. 위반 하나라도 나오면 **기능 작업을 멈추고 이걸 먼저 고친다** (기획서 15장 "보장선이 조용히 무너짐" 대응).
4. 판정 결과는 [gates.md](./gates.md) 의 G4 체크박스에 반영한다.

| # | 한 줄 | 언제 점검하나 |
|---|---|---|
| [B1](#b1) | 사용자가 입력하는 것은 URL 과 값 붙여넣기뿐 | G2 · G4 |
| [B2](#b2) | 사용자가 배우는 명사는 "컬렉션" 하나 | 상시 · G4 |
| [B3](#b3) | 빈 스키마 에디터를 주지 않는다 | G1 · G4 |
| [B4](#b4) | 실패는 빨간 에러가 아니라 상태 문구 | G3 · G4 |
| [B5](#b5) | API·MCP 주소는 접혀 있고 펼치면 보인다 | G1 · G4 |
| [B6](#b6) | 터미널·새 탭·외부 도구가 필요 없다 | G4 |
| [B7](#b7) | MCP 연결은 주소 한 줄 복사 → 붙여넣기 | G4 |

<a id="b1"></a>
## B1 — 입력하는 것은 URL 과 값 붙여넣기뿐

> 컬렉션을 만드는 전 과정에서 사용자가 입력하는 것은 **URL** 과 (필요 시) **값 붙여넣기**뿐이다.

**무엇을 하나** — 새 컬렉션을 처음부터 만든다. 두 번째 소스까지 붙인다.
일부러 매핑이 안 될 만한 사이트를 골라 "못 찾은 필드" 경로를 강제로 밟는다.

**어디를 여나**
- 컬렉션 생성 화면 (URL 입력)
- 스키마 편집 화면
- 소스 추가 화면 · 못 찾은 필드를 묻는 화면

**무엇을 보면 위반인가**
- 셀렉터(`css:`, `.class`, `#id`)를 입력받는 칸이 하나라도 있으면 위반
- XPath · 정규식 · JSONPath(`$.foo`)를 입력받으면 위반
- 타입 코드(`text`, `date` 같은 내부 키)를 **직접 타이핑**하게 하면 위반 (드롭다운에서 한국어 라벨로 고르는 것은 통과)
- "고급 설정" 안에 숨겨 놓아도 **위반이다.** 접는 것으로 면제되는 건 B5 뿐이다

**통과의 모습** — 못 찾은 필드는 이렇게 묻는다:
"이 사이트에서 '마감일'에 해당하는 값을 하나 복사해 붙여넣어 주세요."
붙여넣은 값을 원본 데이터에서 역추적해 경로를 확정하는 것은 시스템의 일이다.

<a id="b2"></a>
## B2 — 사용자가 배우는 명사는 "컬렉션" 하나

> UI 문자열에 어댑터·런·스펙·드리프트·파서 같은 내부 명사가 등장하면 위반.

**무엇을 하나** — 화면 전체의 문자열을 훑는다. 빈 상태·로딩 문구·토스트·확인 다이얼로그·이메일 본문·웹훅 페이로드의 사람이 읽는 필드까지.

**어디를 여나** — 모든 화면. 그리고 grep:

```bash
# 사용자 노출 문자열에 내부 명사가 있는지 — 주석은 걸러진다
grep -rnE '어댑터|드리프트|스펙|런 로그|파서|probe|프로브|컴파일|adapter|drift' \
  apps/web/app apps/web/components --include='*.tsx' | grep -v '^\s*//'
```

**금지 명사와 대체어**

| 내부 명사 | 화면에서는 |
|---|---|
| 어댑터 (adapter) | (노출하지 않는다) |
| 소스 (source) | **사이트** 또는 **출처** |
| 런 (run) | **수집 기록** 또는 **마지막 갱신** |
| 스펙 (spec) | (노출하지 않는다) |
| 드리프트 (drift) | "사이트 구조가 바뀐 것 같아요" |
| probe / 컴파일 | "사이트를 살펴보는 중" |
| 아이템 (item) | **항목** |
| 스키마 (schema) | **표 구성** 또는 **항목 구성** |
| 필드 (field) | **열** 또는 필드 라벨 그대로 |

**무엇을 보면 위반인가**
- 위 표의 왼쪽이 화면 문자열에 그대로 나오면 위반
- 상태 값의 내부 키(`needs_attention`, `healing`)가 그대로 보이면 위반 — 한국어 문구로 옮겨야 한다
- URL 경로나 API 응답 키는 **예외다.** `sources` 는 개발자용 응답이고 B5 로 접혀 있다

<a id="b3"></a>
## B3 — 빈 스키마 에디터를 주지 않는다

> 언제나 **이미 채워진 표**를 주고 사용자는 편집만 한다.

**무엇을 하나** — 새 컬렉션을 만든다. URL 하나를 넣고 첫 표가 나오는 순간을 본다.

**어디를 여나** — URL 입력 직후의 첫 결과 화면.

**무엇을 보면 위반인가**
- 첫 화면에 "필드를 추가하세요" 같은 **빈 상태**가 나오면 위반
- 열이 0개인 표가 나오면 위반
- 필드 추가가 유일한 시작 동작이면 위반

**통과의 모습** — 필드가 이미 추측돼 채워져 있고, 사용자가 하는 일은 두 가지뿐이다: **이름 바꾸기**, **필요 없는 것 지우기.**
추론이 실패했을 때조차 빈 표를 주면 안 된다 — 그때는 상태 문구를 주고(B4) 다시 시도하거나 값을 붙여넣게 한다(B1).

---

<a id="b4"></a>
## B4 — 실패는 빨간 에러가 아니라 상태 문구

> 스택 트레이스나 HTTP 코드가 노출되면 위반.

**무엇을 하나** — 일부러 깨뜨린다. 최소 세 가지:
1. 어댑터 스펙의 경로를 손으로 틀리게 바꾼다 (드리프트 유발 — G3 판정과 같은 조작)
2. 존재하지 않는 URL 로 컬렉션을 만들어 본다
3. 목록이 아닌 페이지(예: 회사 소개)로 컬렉션을 만들어 본다

**어디를 여나** — 컬렉션 목록 · 컬렉션 상세 상단의 출처 상태 · 읽기 피드 · 소스 추가 화면.

**무엇을 보면 위반인가**
- HTTP 상태 코드(`500`, `404`, `Failed to fetch`)가 화면에 있으면 위반
- 스택 트레이스·예외 이름(`TypeError`, `ZodError`)이 보이면 위반
- 빨간 배너 하나로 화면 전체를 죽이면 위반 — **깨진 소스만 상태가 바뀌고 나머지는 살아 있어야 한다** (원칙 ④)
- 데이터가 있는데 화면이 비어 버리면 위반 — 마지막 성공 데이터를 계속 보여주되 나이를 표시한다

**통과의 모습**

| 상태 | 화면 문구 (예시) |
|---|---|
| `ok` | "오늘 오전 6시에 갱신" |
| `healing` | "이 사이트 구조가 바뀐 것 같아요. 다시 맞추는 중입니다 · 6시간 전 자료를 보여드리는 중" |
| `needs_attention` | "이 사이트에서 자료를 가져오지 못하고 있어요. 확인이 필요합니다" |
| `paused` | "이 사이트는 잠시 쉬는 중이에요" |

`runs.error_summary` 는 **사용자에게 보여줄 문구**를 담는 칸이다. 내부 오류 메시지를 그대로 넣지 않는다.

<a id="b5"></a>
## B5 — API·MCP 주소는 접혀 있고, 펼치면 언제든 보인다

> 첫 진입 화면에 엔드포인트 문자열이 강제 노출되면 위반. **숨겨서 못 찾게 해도 위반.**

**무엇을 하나** — 로그아웃 상태에서 시작해 로그인하고, 컬렉션 상세에 처음 들어간다. 스크롤하지 않은 첫 화면을 본다. 그 다음 개발자용 정보를 찾아본다.

**어디를 여나** — 컬렉션 상세 첫 화면 · 컬렉션 생성 완료 화면.

**무엇을 보면 위반인가**
- 첫 화면(스크롤 전)에 `https://api.…/v1/contest` 같은 문자열이 그대로 보이면 위반
- API 키가 접힘 없이 노출되면 위반
- **반대로**, 개발자용 정보를 세 번 이상 클릭해야 찾을 수 있으면 그것도 위반. 접힘은 한 번 클릭으로 열려야 한다
- 열었을 때 접힘 상태가 기억되지 않아 매번 다시 접히면 사용성 문제지만 위반은 아니다

**통과의 모습** — 컬렉션 상세에 "개발자용" 같은 접힌 영역이 하나. 펼치면 REST URL · 쿼리 파라미터 예시 · MCP 주소 · 키가 전부 거기 있다.

<a id="b6"></a>
## B6 — 터미널·새 탭·외부 도구가 필요 없다

> 표를 만들고 결과를 보기까지 curl 실행이나 파일 다운로드를 요구하는 단계가 있으면 위반.

**무엇을 하나** — 로그인부터 표 확인까지 **브라우저 탭 하나로** 끝까지 간다. 도중에 다른 도구를 쓰고 싶어지는 지점을 센다.

**어디를 여나** — 컬렉션 생성 전 과정.

**무엇을 보면 위반인가**
- "아래 명령을 터미널에서 실행하세요"가 있으면 위반
- CSV/JSON 파일을 내려받아야 결과를 볼 수 있으면 위반
- 외부 사이트로 이동해 무언가 발급받아 돌아와야 하면 위반 (구글 로그인은 예외 — P4 로 확정한 유일한 외부 왕복)
- 결과 확인이 새 탭에서만 되면 위반 (API 응답을 **보고 싶어서** 새 탭을 여는 건 사용자의 선택이므로 통과)

<a id="b7"></a>
## B7 — MCP 연결은 주소 한 줄 복사 → 커넥터에 붙여넣기

> 설정 JSON 편집이나 로컬 설치를 요구하면 위반.

**무엇을 하나** — 컬렉션 화면의 "AI 에 연결"을 누르고, 안내대로만 해서 실제 커넥터에 붙인다. 그리고 "이번 주 마감 뭐 있어?"를 물어본다.

**어디를 여나** — 컬렉션 상세 · MCP 연결 안내.

**무엇을 보면 위반인가**
- `claude_desktop_config.json` 같은 파일을 편집하라고 하면 위반
- `npx`/`pnpm` 설치 명령이 안내에 있으면 위반
- 주소와 키를 사용자가 손으로 합치게 하면 위반 — 복사 버튼 하나로 완성된 한 줄이 나와야 한다
- 실제로 붙여넣었는데 도구 목록이 안 뜨면 위반 (안내가 맞아도 동작이 안 되면 미통과)

**통과의 모습** — 버튼 하나 → 클립보드에 완성된 주소 한 줄 → 커넥터 설정에 붙여넣기 → 끝.
안내는 한 장을 넘지 않는다.

> **강등 주의** — G4 강등 규칙 2번(로컬 stdio 로 낮추기)은 이 보장선을 깨는 것이다.
> 발동하면 데모에서 "이건 개발자 경로"라고 명시하고, 3장에서 MCP 를 가장 차별적이라 한 근거가
> 약해졌음을 발표 자료에 적는다.

## 자동 점검

문자열 규약(B2·B4 일부)만 기계로 잡을 수 있다. 나머지는 사람이 화면을 봐야 한다.

- **[`apps/web/lib/guardrails.ts`](../apps/web/lib/guardrails.ts)** — 금지 명사 목록과 판정 규칙.
  주석은 검사하지 않고(개발자용이므로) 문자열 리터럴과 JSX 텍스트만 훑는다.
  HTTP 상태 코드 노출(`HTTP 404`, `500 에러`)도 같이 잡는다 — B4.
- **[`apps/web/lib/guardrails.test.ts`](../apps/web/lib/guardrails.test.ts)** — `apps/web` 의 `app`·`components`·`lib` 를 실제로 스캔한다.

```bash
pnpm --filter @endpointer/web test
```

새 금지어가 생기면 `FORBIDDEN_UI_TERMS` 에 추가한다. 이 문서의 B2 대체어 표와 같이 고쳐라.
위 B2 절의 `grep` 은 이 테스트가 없는 경로(예: 워커가 만드는 `runs.error_summary` 문구)를 볼 때 쓴다.

**기계가 잡을 수 있는 것과 없는 것을 헷갈리지 마라.** B1·B3·B5·B6·B7 은 화면을 열어야만 판정된다.
테스트가 초록이라고 보장선이 지켜진 게 아니다.
