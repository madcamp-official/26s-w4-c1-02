# 관문 체크리스트 G0~G5

> 기획서 13장을 체크박스로 옮긴 것. **하루의 시작에 다음 관문 조건을 소리 내어 읽고, 하루의 끝에 판정한다.**
> 2026-07-27 스펙 델타([spec-delta-0727.md](./spec-delta-0727.md) 14절)를 반영해 갱신했다 —
> 델타에서 온 항목은 `[Δ]` 로 표시한다.

## 판정 규칙 (기획서 13장)

- 작업량과 속도를 추정하지 않는다. 각 관문에는 **통과 판정 조건만** 있다.
- **관문은 말이 아니라 화면으로 판정한다.** 구두 보고가 아니라 실제로 돌려서 본다.
- 판정값은 **통과/미통과 둘뿐**이다. "거의 됨"은 미통과다.
- 미통과면 **그 자리에서** 강등 규칙을 발동할지 결정한다. 다음 관문으로 부채를 넘기지 않는다.
  강등은 실패가 아니라 설계된 경로다.
- 체크박스는 **직접 돌려서 눈으로 본 것만** 채운다. 채울 때 판정일과 재현 근거를 적는다.

| 관문 | 이름 | 한 줄 판정 | 시점 | 담당 | 상태 |
|---|---|---|---|---|---|
| G0 | 계약 고정 | 가짜 데이터로 두 트랙이 서로를 안 기다린다 | Day 1 시작 | 공동 | **통과** |
| G1 | URL 하나가 아이템이 된다 | 그 자리에서 정한 낯선 URL 에서 아이템이 나온다 | Day 1 종료 | A / B 각자 | **통과** (07-27) |
| G2 | 두 번째 소스가 붙는다 | 두 출처가 한 표에 같은 형식으로 섞인다 | Day 2 종료 | 합류 | CLI 통과 · **화면 붙이기 남음** |
| G3 | 계속 돈다 | 일부러 깨뜨려도 혼자 고치고, 나머지는 산다 | Day 3 종료 | A / B 각자 | 진행 중 |
| G4 | 배포 · MCP · 낯선 사람 | 도메인에서 처음 본 사람이 혼자 성공한다 | Day 4 종료 | 합류 | **배포 선행 완료** (07-27) |
| G5 | 데모 | 끊김 없이 한 번에 녹화된다 | Day 5 종료 | 공동 | — |

```
G0 ─┬─→ G1(A) ──→ G2 ──→ G3(A) ──→ G4 ──→ G5
    └─→ G1(B) ──┘        G3(B) ──┘
```

## G2 — 두 번째 소스가 붙는다 (첫 합류)

**여기까지가 원 기획안의 v1 이고, 제품이 성립하는 지점이다.**
파이프라인·CLI 로는 전부 실증됐다 ([day2-part-a.md](./day2-part-a.md) §6). 남은 것은 **화면의 "사이트 붙이기" 흐름**이다.

- [x] 서로 다른 호스트 2곳의 아이템이 **하나의 표**에 섞여 나온다 — bizinfo 30건 = bizinfo 15 + k-startup 15 (07-27)
- [x] 출처 뱃지로 구분된다 (화면 표 · 07-27)
- [x] 두 번째 소스의 필드가 기존 스키마에 **자동으로 매핑**된다 — k-startup 5/6 · wevity 4/6 (CLI `attach`)
- [x] 못 찾은 필드만 사용자에게 물어본다 (전부 다시 묻지 않는다) — CLI 는 됨 · **화면 붙이기 흐름은 미구현**
- [x] 값을 붙여넣어 그 필드를 해결한다 — `--paste "deadline=D-32"` 로 실증 (traceValue · LLM 없음) · **화면은 미구현**
- [x] 날짜가 두 소스에서 같은 형식으로 나온다
- [x] 금액이 두 소스에서 같은 형식으로 나온다
- [ ] 분류값 매핑이 동작한다 — 지금 `category` 에 `사업화`(k-startup)·`내수`(bizinfo)가 그대로 섞여 있다 (day2 §7-4)
- [x] `GET /api/v1/{slug}` 가 **실제 수집 데이터**로 응답한다 (bizinfo · k-startup 슬러그)
- [x] 필터·정렬·페이지가 API 에서 동작한다
- [x] `sources` 에 소스별 상태가 들어 있다
- [x] 값에 마우스를 올리면 원문 조각이 보인다 — 시드 기준 확인. 실수집 컬렉션에서 재확인 필요 (day2 §8 seed raw_json 형태 차이)
- [x] **화면 생성 흐름이 파이프라인을 부른다** — 07-27 배선 완료 (`/internal/preview`·`/internal/collections` · ADR A30).

- [ ] **화면 "사이트 붙이기" 흐름** — attach 를 워커 HTTP 문으로 노출하고 화면에서 못 찾은 칸을 붙여넣기로 해결 (B1 의 화면 실체)
